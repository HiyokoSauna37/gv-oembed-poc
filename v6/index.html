GVT1

Per-field inert marker test. Each oEmbed metadata field carries its own <b>-only marker so a read-back can say which field, if any, reaches the consumer's embed wrapper unencoded.

  • title → GVT1B
  • provider_url → GVP1B (also tests an attribute break-out)
  • author_name → GVA1B
  • author_url → GVD1B
  • url → GVU1B
  • thumbnail_url → GVH1B

Markers are inert: no script, no event handler, no outbound request.
